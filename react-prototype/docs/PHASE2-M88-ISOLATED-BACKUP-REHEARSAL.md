# M88 — isolated backup and restore rehearsal

Test-only actual disk I/O inside a fresh self-created temporary directory. No caller path, byte input, handle or external target. Exclusively creates fixed synthetic target/backup files, captures original bytes and SHA-256, syncs backup, writes a fixed edited revision, verifies backup and target generation before restoring, compares restored bytes. Two controlled refusal scenarios: same-size backup corruption and changed target generation. Handles closed and private fixture cleaned. Five tests via existing security glob. No actual game reads or writes, production import, IPC, UI, operation authority, atomicity or power-loss durability claim. The in-place fixture restore is not a production algorithm; M89 requires stronger backup manifest and integrity checks, M90 isolated interruption/restart evidence. Strict Ubuntu24 gate mandatory; no merge/release.
