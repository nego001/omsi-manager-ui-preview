# M75 — Preferred location unavailable / rediscovery

Distinguishes a completed bounded Steam search with no preferred-path match from an inconclusive search. Neither proves that a game moved or was uninstalled. Keeps the saved fingerprint even if a search fails, the library is disconnected or a candidate disappears. Offers retry and existing native-confirmed replacement; never guesses a replacement, even with only one candidate. If search succeeds but does not find the preference, the UI explains possible causes and points to Steam library registration or custom-folder search. Custom-folder results are not automatically stored as Steam preferences. Adds a synthetic Electron regression that corrupts a temporary index, physically moves a fixture to another temporary Steam library, confirms that cancel preserves preference, and explicitly replaces it. Unit test rejects inheritance by a relocated path. No game file reads or writes in production, no new grant or bypass, no proof of physical disk identity. Draft stack only, Ubuntu24 strict gate remains mandatory.
