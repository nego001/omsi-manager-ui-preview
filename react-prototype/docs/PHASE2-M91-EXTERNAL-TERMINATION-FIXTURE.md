Test-only extension of M90. Separate Node child, IPC checkpoint message after synced fixture writes or publication; the child waits without advancing. Parent uses its owned ChildProcess handle, not a PID supplied externally, to send SIGKILL and verifies exit signal before starting a new inspection process. Five checkpoint observations plus read-only repeated inspection, missing IPC refusal and unrelated sentinel regression (four tests). No automatic recovery, real game access, production imports, operation authority or power-loss/durability proof. Windows signal is Node's process-termination abstraction, not POSIX semantics. Checkpoints are after completed operations, not mid-system-call crashes. M92: restart recovery prerequisites and independent trust, no production recovery.
