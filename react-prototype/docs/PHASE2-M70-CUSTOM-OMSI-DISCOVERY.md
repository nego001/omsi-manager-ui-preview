# M70 — Search in a user-selected custom directory (OMSI 2)

Adds an explicit **Procurar em outra pasta** button on the OMSI 2 card. First native picker authorizes a bounded metadata search. A second native picker must confirm a unique candidate before the existing read-only inspection grant is issued. A folder name is not evidence: both Vehicles/maps directories and a regular Omsi.exe marker must exist. Hidden directories and symlinks are skipped; no game file is opened, no write or execution. Limits: depth 3, 128 directories and 1024 enumerated entries, no filesystem root selection. Incomplete/ambiguous/no-match results never auto-authorize inspection. Search only inside a selected directory or mounted volume subdirectory, not all disks; the current OMSI-only feature does not yet search custom ETS2/ATS locations. Metadata path checks are not atomic containment; races cannot be ruled out. Existing Ubuntu24 strict gate and Draft status unchanged. Tests use synthetic fixtures.
