# N02 — Red/amber dashboard layout
User-approved exact reference is pinned in N01. This branch implements the first live composition: amber/red theme, full-width panorama, four actual session metrics, three simulator cards, quick actions and right diagnostic/storage/activity rail. The native UI retains all existing routes, read-only diagnostics and blocked operations. No invented storage counts or install statuses. Crops are not transferred by the connector: put the six exact WebP files into src/art/negresco using the N01 extraction script or approved ZIP. Optional Vite imports allow compilation without assets; in that state the app is not visually faithful. Hero image includes the approved brand art; live controls are separately rendered underneath and differ from the mockup. No pixel-identical claim; runtime, binary integration and visual acceptance remain open. No merge or release.
