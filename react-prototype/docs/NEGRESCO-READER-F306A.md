# F3.06a — O3D structural mesh evidence (synthetic subset)

F3.05 CI 45679063180: 126/126 tests per OS (Windows and Ubuntu 22.04), no skips or failures. F1 Linux packaged gate remains unresolved.

Independent bounded parser based on the documented O3D layout at https://github.com/openOMSI-org/openOMSI/blob/main/docs/FORMATS.md (section .o3d). Accepts only synthetic memory buffers with v1 or v3, short or long indices as applicable, ordered vertex/triangle/material/matrix sections, and no trailing bytes. Finite XYZ, normals, UV, material floats and matrix; validates vertex and material indices, records per-material triangle counts, repeated-index triangle count, raw coordinate/UV bounds, texture path candidates, pivot matrix and source SHA-256. Texture candidates use F3.01 portable path validation; none resolved. Strict caps on bytes, vertices, triangles, materials and texture-name length. Outputs are frozen. No render, mesh export, unit conversion, matrix application, real model loading or execution. Repeated-index count is not complete geometric degeneracy or topology validation.

Unsupported versions (including >=4), scrambling/encryption, bones, nonportable names, unexpected sections/order, and any trailing bytes are refused. Synthetic scope is not a real security boundary. 13 new tests, expected 139 per OS, pending CI. F3.06 is partial, not homologated: PMD/PMG/PMC binary interpretation remains pending. SCS official format roles: https://modding.scssoft.com/wiki/Documentation/Engine/Formats ; no invented binary layout or claim that O3D support implies SCS support. No merge or release.
