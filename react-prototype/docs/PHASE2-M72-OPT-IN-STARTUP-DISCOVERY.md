# M72 — Optional startup Steam discovery

A persisted local opt-in, default off, invokes the existing bounded Steam discovery once per renderer document on startup. Only a boolean is persisted. Results are refreshed rather than cached, with no stored paths, picker, inspection grant, or game file writes. The existing main IPC authorization, one-flight guard, document signal and path-free counts remain. A synchronous renderer busy ref prevents duplicate discovery while in flight, including React strict effect repetition. The checkbox is available in Games and takes effect on subsequent startup. Turning it off prevents future startup scans, not an already pending filesystem call. A synthetic real-Electron reload regression checks opt-in, three game counts, zero picker calls, one batch per document, disable, and unchanged read-only behavior. The test replaces only the Electron main home lookup inside a disposable fixture. No whole disk scanning or authorization persistence. Strict Ubuntu24 gate unchanged, all PRs Draft.
