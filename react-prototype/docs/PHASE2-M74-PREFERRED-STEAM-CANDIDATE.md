# M74 — Preferred Steam candidate
Explicit Confirmar e lembrar action requires the same native confirmation as M73. For OMSI, the inspection must succeed before returning a preference. Stores only a versioned SHA-256 fingerprint of game ID and candidate path in localStorage, not a full path or opaque session ID; this is not an authorization token, encryption or proof of installation identity. On a fresh discovery the main compares the saved fingerprint only against current bounded candidates and returns the current opaque candidate ID. Reordering libraries does not change preference. No remembered path is used to open a file; inspection still needs native confirmation and a new one-shot grant. Preference can be replaced by confirming another candidate or forgotten without changing the game. A missing match is not evidence of a move, deletion or uninstall. Tests cover refresh/reorder/forget, wrong game or epoch and stale preferences. No startup custom scan, no persistent access grant, no writes to game data. Stacked Draft, Ubuntu24 strict gate remains mandatory.
