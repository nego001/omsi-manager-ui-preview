# M89 — synthetic backup manifest integrity

Test-only extension of M88 in a fresh self-owned temporary directory. Three exclusively created fixed files (target, backup, manifest) with bounded reads, synced writes and handle cleanup. Canonical manifest binds a random session identifier, synthetic revision labels, fixed target/backup roles, lengths and SHA-256 digests. Exact manifest bytes are compared with an independent in-memory expected record; untrusted JSON is not interpreted. Backup and expected edited target are compared with independent captured bytes and digest before any restore. Eight scenarios (normal plus seven refusal variants), six tests via existing security glob. Includes coordinated backup/digest rewrite, session/revision/role tampering, malformed manifest, corrupt backup and changed target. No arbitrary paths, real game files, secrets/digests in report, runtime imports, IPC or write permission. In-memory anchor is not authentication, persisted trust, proof of target identity, atomicity or power-loss durability. M90: interrupted fixture recovery with process restart and independently established trust requirements. Strict Ubuntu24 gate mandatory; no merge/release.
