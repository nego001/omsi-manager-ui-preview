F3.01 reader CI run 45673906715: 80/80 tests on Windows and Ubuntu22. Main preview run 45673906612 failed on known packaged Linux gate and separate historical docs-only observation; not waived. F1/F2 unchanged.

Add in-memory synthetic signature recognizer: ZIP local/empty archive signatures, RAR4/5, 7z, SCS# HashFS signature candidate, DDS, PNG, JPEG, Ogg, RIFF/WAVE. Minimum header sizes and limited fixed fields (DDS header size/dimensions, PNG IHDR/dimensions, Ogg version/lacing-table bounds, WAVE family/size) distinguish incomplete or invalid header from recognized signature. Non-WAVE RIFF stays unsupported. Extension mismatch reported; ZIP with .scs stays ZIP, does not classify ETS2/ATS. OMSI bus/ovh/cfg/osc/o3d and SCS sii/sui/pmd/pmg/pma/tobj/bank extension hints explicitly unverified. No actual parser, archive integrity, CRC, version decoding, image/audio decoding, decompression, game or compatibility certification. Some short valid prefixes intentionally unknown; rules are conservative fixture contracts, not full format specs. 16 MiB input cap; no raw bytes output, file path or host access. Ten new tests, pending CI (90 total per OS). Next F3.03 bounded ZIP container index, then additional formats as supported. No merge/release.
